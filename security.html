Segurança

Segurança by design

A NewToken é construída sobre uma arquitetura de segurança em primeiro lugar. Cada camada da plataforma — do acesso à API ao armazenamento de dados — é projetada para proteger seus dados e os dados dos seus clientes.

🔒

Criptografia TLS 1.3

Todos os dados em trânsito são criptografados com TLS 1.3. HSTS é aplicado em todos os domínios.

🛡️

Criptografia de Dados em Repouso

Todos os dados armazenados são criptografados com AES-256. As chaves são gerenciadas com rotação automática.

🔑

Acesso Zero Trust

Serviços internos se comunicam via redes privadas com TLS mútuo. Nenhum serviço tem confiança implícita — toda requisição é autenticada e autorizada.

API Segurança

Acesso seguro à API

As chaves de API da NewToken são escopadas, rotacionáveis e auditáveis. Cada chave pode ter permissões granulares limitando o acesso a endpoints e operações específicas.

  • ✓ Chaves de API escopadas com controle por endpoint
  • ✓ OAuth 2.0 para integrações de terceiros
  • ✓ Assinatura de requisições de webhook com HMAC-SHA256
  • ✓ Rate limiting e proteção DDoS em todos os endpoints
  • ✓ Allowlist de IPs disponível para contas enterprise
Proteção de Dados

Isolamento de dados e privacidade

A NewToken implementa isolamento rigoroso de dados entre tenants. Os dados dos seus clientes nunca são acessíveis a outros clientes nem usados para outros fins além dos serviços configurados.

  • ✓ Isolamento lógico de tenants com chaves de criptografia separadas por conta
  • ✓ Conteúdo de mensagens não armazenado além da janela de confirmação de entrega
  • ✓ Nenhum compartilhamento ou revenda de dados a terceiros em nenhuma circunstância
  • ✓ Políticas de retenção de dados configuráveis por conta
  • ✓ Acordos de processamento de dados conformes com LGPD e GDPR disponíveis
Infraestrutura

Infraestrutura security

🏗️

Isolamento de Rede

Toda a infraestrutura de produção roda em sub-redes privadas. O acesso público é limitado a load balancers com proteção WAF.

📝

Logs de Auditoria

Logs de auditoria completos para todas as chamadas de API, eventos de autenticação e ações administrativas. Logs imutáveis retidos por 12 meses.

🔍

Gestão de Vulnerabilidades

Testes de penetração regulares, varredura automática de vulnerabilidades em dependências e programa de divulgação responsável.

🔄

Disponibilidade e Backup

Deploy multi-região com failover automático. Backups contínuos do banco de dados com recuperação point-in-time de até 30 dias.

📋

Resposta a Incidentes

Monitoramento de segurança 24/7 com procedimentos definidos de resposta a incidentes. Clientes afetados são notificados em até 72 horas após qualquer incidente confirmado.

🧑‍💼

Controle de Acesso

O acesso à produção pelos funcionários da NewToken é restrito, limitado no tempo e requer aprovação gerencial. O acesso é totalmente auditado.

Conformidade com a Plataforma Meta

Conformidade com a plataforma Meta

A NewToken opera em total conformidade com os Termos de Plataforma da Meta, Políticas de Desenvolvedor e requisitos de uso de dados. Como Tech Provider certificado, nossas práticas de tratamento de dados foram revisadas e aprovadas pela Meta.

Política de Dados da Plataforma Meta

Dados obtidos pelas APIs da Meta são usados apenas para fornecer os serviços de automação e mensagens configurados pelos nossos clientes. Não analisamos, mineramos ou reaproveitamos dados da Plataforma Meta além da prestação do serviço.

Divulgação Responsável

Se você descobrir uma vulnerabilidade de segurança na plataforma NewToken, reporte de forma responsável para security@newtoken.win. Respondemos a todos os relatórios válidos em até 48 horas.
