Security

Security by design

NewToken is built on a security-first architecture. Every layer of the platform — from API access to data storage — is designed to protect your data and your customers' data.

🔒

TLS 1.3 Encryption

All data in transit is encrypted using TLS 1.3. We do not support TLS 1.0 or 1.1. HSTS headers are enforced on all domains.

🛡️

Data Encryption at Rest

All stored data is encrypted at rest using AES-256. Encryption keys are managed using a dedicated key management service with automatic rotation.

🔑

Zero Trust Access

Internal services communicate over private networks with mutual TLS. No service has implicit trust — every request is authenticated and authorized.

API Security

Secure API access

NewToken API keys are scoped, rotatable, and auditable. Each key can be assigned granular permissions limiting access to specific endpoints and operations.

  • ✓ Scoped API keys with per-endpoint permission control
  • ✓ OAuth 2.0 for third-party integrations
  • ✓ Webhook request signing with HMAC-SHA256
  • ✓ Rate limiting and DDoS protection on all endpoints
  • ✓ IP allowlisting available for enterprise accounts
Data Protection

Data isolation & privacy

NewToken implements strict data isolation between tenants. Your customers' data is never accessible to other customers or used for any purpose beyond the services you configure.

  • ✓ Logical tenant isolation with separate encryption keys per account
  • ✓ Message content not stored beyond delivery confirmation window
  • ✓ No data sharing or resale to third parties under any circumstances
  • ✓ Configurable data retention policies per account
  • ✓ LGPD and GDPR compliant data processing agreements available
Infrastructure

Infrastructure security

🏗️

Network Isolation

All production infrastructure runs in private subnets. Public access is limited to load balancers with WAF protection.

📝

Audit Logging

Comprehensive audit logs for all API calls, authentication events, and administrative actions. Logs are immutable and retained for 12 months.

🔍

Vulnerability Management

Regular penetration testing, automated dependency vulnerability scanning, and a responsible disclosure program for security researchers.

🔄

Availability & Backup

Multi-region deployment with automatic failover. Continuous database backups with point-in-time recovery up to 30 days.

📋

Incident Response

24/7 security monitoring with defined incident response procedures. Affected customers are notified within 72 hours of any confirmed data incident.

🧑‍💼

Access Control

Production access for NewToken employees is restricted, time-limited, and requires manager approval. Access is fully audited.

Meta Platform Compliance

Meta Platform compliance

NewToken operates in full compliance with Meta's Platform Terms, Developer Policies, and data use requirements. As a certified Tech Provider, our data handling practices have been reviewed and approved by Meta.

Meta Platform Data Policy

Data obtained through Meta's APIs is used only to provide the automation and messaging services configured by our business clients. We do not analyze, mine, or repurpose Meta Platform Data beyond service delivery.

Responsible Disclosure

If you discover a security vulnerability in the NewToken platform, please report it responsibly to security@newtoken.win. We respond to all valid reports within 48 hours.
