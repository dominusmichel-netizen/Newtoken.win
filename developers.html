NewToken API Reference

The NewToken API provides a unified, RESTful interface for interacting with Meta's messaging platforms. All requests are made over HTTPS and return JSON responses.

Base URL:
https://api.newtoken.win/v2

All API requests must include your API key in the Authorization header. Keys can be generated from the NewToken dashboard under Settings → API Keys.

Authentication

NewToken uses Bearer token authentication. Include your API key in every request using the Authorization header.

HTTP Request 
POST https://api.newtoken.win/v2/messages
Authorization: Bearer nt_live_xxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json

Quick Start

Send your first WhatsApp message using the NewToken API in under 2 minutes.

1. Install the SDK

Terminal 
# Python
pip install newtoken-sdk

# Node.js
npm install @newtoken/sdk

2. Send a message

example.py 
from newtoken import Client

client = Client(api_key="nt_live_xxxxxxxxxxxx")

msg = client.whatsapp.messages.send(
    phone_number_id="YOUR_PHONE_NUMBER_ID",
    to="55119999000",
    body="Hello from NewToken!"
)

print(msg.id, msg.status)
# → wamid.HBgL...  sent

Mensagems API

Send and receive messages across Meta's messaging platforms through a unified endpoint.

POST
/v2/whatsapp/messages
Send a WhatsApp message to a recipient
GET
/v2/whatsapp/messages/{message_id}
Retrieve message status and metadata
POST
/v2/instagram/messages
Send an Instagram Direct Mensagem

Request Parameters

Parameter Type Required Description
phone_number_id string required Your Meta phone number ID from Business Manager
to string required Recipient's phone number in E.164 format
body string required Mensagem text content (max 4096 characters)
template_id string optional ID of an approved Meta message template

Webhooks

NewToken delivers real-time events to your endpoint via authenticated HTTPS POST requests. Configure your webhook URL in the NewToken dashboard.

Webhook verification

Meta requires webhook endpoints to respond to a GET verification request before events are delivered. NewToken handles Meta's verification protocol automatically — you only need to implement the NewToken signature check.

webhook_handler.py 
from flask import Flask, request
from newtoken import verify_signature

app = Flask(__name__)

@app.route("/webhook", methods=["POST"])
def receive_event():
    # Verify NewToken signature
    sig = request.headers.get("X-NewToken-Signature")
    if not verify_signature(request.data, sig):
        return "Unauthorized", 401

    event = request.json()
    handle_event(event)
    return "", 200

WhatsApp Business Integration

NewToken is certified to use the WhatsApp Business API via the Cloud API hosted by Meta. Before sending messages, your business client's WhatsApp Business Account (WABA) must be connected to NewToken.

Permissions required

The following Meta API permissions are required and pre-approved on the NewToken app:

whatsapp_business_management  ·  whatsapp_business_messaging  ·  pages_manage_metadata

Embedded Signup

Embedded Signup allows your business clients to connect their WhatsApp Business Account to NewToken without leaving your product. After connection, NewToken manages token refresh and API access automatically.

Implementation flow

1
Launch Embedded Signup modal
Client clicks "Connect WhatsApp" button in your product. NewToken opens the Meta Embedded Signup flow in an iframe.
2
Meta authenticates client
Client authorizes NewToken to access their WhatsApp Business Account. Meta issues a short-lived access token.
3
NewToken stores WABA ID
NewToken exchanges the token for a system token and stores the WABA ID. Automation is immediately available.

Rate Limits

NewToken enforces rate limits to maintain API stability. Limits are applied per API key.

EndpointLimitWindow
/v2/whatsapp/messages 1,000 requests per minute
/v2/instagram/messages 500 requests per minute
All other endpoints 200 requests per minute
When a rate limit is exceeded, the API returns HTTP 429 Too Many Requests. Retry after the duration specified in the Retry-After response header.
