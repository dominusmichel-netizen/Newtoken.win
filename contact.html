Common questions

How do I get API credentials?

Create a NewToken account and navigate to Settings → API Keys. Your first key is generated automatically. Scoped keys for production use can be created from the same panel.

Can I connect my existing WhatsApp Business account?

Yes. NewToken's Embedded Signup allows you to connect an existing WhatsApp Business Account (WABA) or create a new one through the Meta onboarding flow directly inside NewToken.

Is there a free trial?

NewToken offers a sandbox environment with limited API access for testing integrations. Contact our sales team to learn about trial options for production workloads.

What support is included?

All plans include email support with a 48-hour response SLA. Enterprise plans include a dedicated account manager and priority support with a 4-hour response window.
